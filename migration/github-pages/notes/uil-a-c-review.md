# UIL Subchapters A–C: review for the Standard

**Status:** Non-normative drafting notes, reviewed against the [2026–27 UIL Constitution and Contest Rules, Subchapters A–C](https://www.uiltexas.org/policy/constitution/general/overview). This is a functional comparison, not an adoption of UIL text or numbering.

| UIL subject | Treatment in this Standard |
| --- | --- |
| Name | Use the agreed title: *Interscholastic Competition Standard for Home-Education Programs, Teams, and Students*. Name a steward or administering entity only after one is selected. |
| Objectives | Include educational experience, fair interscholastic competition, common eligibility and conduct rules, accountability to officials, and possible use as a model for external membership categories. Do not limit competitors to home-school organizations. |
| School and member-school definitions | Define *school* for this Standard as the organization that adopts the rules and represents students. Do not equate that role with institutional responsibility for the student's education under HS-BASE or with current UIL/TAPPS membership. Membership details follow in the next section. |
| Student, contest, and team | Define broadly enough for athletics, academics, and performing arts. Keep an individual student representing a school distinct from an unaffiliated entrant, which is reserved. |
| Administrative roles, districts, conferences, regions, sponsors, and recruiting | Define each when its governance, classification, activity, or eligibility rule is drafted. Do not import UIL's school-district-based offices into a protocol for independent organizations. |
| Enrollment, high school, junior high, transfer, calendar, and school week | Develop precise protocol meanings where needed for competition grade, the high-school clock, seasons, transfer, and academic conformance. The UIL definitions cannot simply be copied because the adopting school need not provide the student's educational program. |
| Media and broadcast terms | Defer until contest, media-rights, or publication rules require them. |
| Computation of time to act | Defer the detailed counting rule until the Standard sets notice, challenge, appeal, and payment deadlines. Use one common rule at that point. |

This review supports following UIL's **subject order** while using the Standard's own headings and numbering. TAPPS can be mapped by function in a parallel review, regardless of whether a provision is labeled Constitution or By-Laws.
